검토일: 2026-09-27. 현재 제품 계약을 기준으로 공개 API를 유지하면서 수정했다.

| 중간 | 서버 진입점에 클라이언트 구성·정적 제공·분석·세계관·플레이 API가 혼재했다. | `src/server/routes/`와 `clients.js`, `settings.js`, `world_store.js`, `http.js`로 책임을 분리했다. |

소스 런타임 파일은 모두 600줄 미만이다. 기존 코드를 기능별로 옮겼으므로 전체 코드량이나
실제 토큰 사용량이 같은 비율로 감소했다는 뜻은 아니다. 필요한 기능의 파일만 읽도록
탐색 범위를 줄인 것이며, 후보 사전·payload 병합·파이프라인처럼 아직 큰 모듈은
정확한 심볼로 해당 함수부터 읽는다. 줄 수만 맞추기 위한 추가 분할은 하지 않았다.

## 설정 경계

- `.env`: `CF_ACCOUNT_ID`, `CF_API_TOKEN`, `GEMINI_API_KEY`, `CF_AI_GATEWAY_TOKEN`만 허용한다.
- 일반 서버 설정: 셸/CI > `config/runtime.local.json` > `config/runtime.json` 순서다.
- `.env`와 로컬 JSON은 Git 제외 및 HTTP 비공개다. 검토 중 자격증명 값을 출력하지 않았다.
- MCP의 `NOVEL_IF_LIBRARY`와 독립 평가 스크립트의 셸 옵션은 기존 계약을 유지한다.
  이들은 `.env`를 일반 설정 저장소로 사용하지 않는다.
- `src/config.js`는 분석 사전·샘플 메타데이터이며 서버 런타임 설정 파일이 아니다.

## 검증

- `npm test`: 572개 통과, 실패 0개. 설정 우선순위·비밀 키 제한·타입 검증·HTTP 접근 제한을 포함한다.
- Chromium: 플레이 초기화, 모의 SSE 턴과 선택지, 종료, 새로고침 후 종료 복원,
  세계관·검수·기록·원문 분석 경로 및 모바일 너비 확인. JS 예외와 자산 로딩 실패 없음.
- `git diff --check` 통과. `.env`와 로컬 JSON이 추적되지 않음을 확인했다.
- 브라우저 턴은 모의 응답으로 검증했다. 실제 유료 LLM 호출 품질은 이번 구조 검토 범위에서 실행하지 않았다.

실행 중인 서버는 재시작해야 새로운 모듈과 설정 분리가 적용된다.
